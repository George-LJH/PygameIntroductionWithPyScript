### Pygame + PyScript
This is my intro to PyGame which I compiled to WASM with PyScript
### Instructions
Use WASD or Arrow Keys to move  
You can teleport by holding down the keys that correspond to the direction you want to teleport in and pressing space  
P to pause the game  
You need to avoid the red lasers, the yellow lasers are an indicator of where the next laser will land.  
After teleporting, you will have 0.25 second of invincibility  
You can teleport once every 0.5 second  
To see if you can teleport yet, You can look at the top left or look at your teleport preview; if the teleport preview is green, you can teleport. If it is red, you cannot  


**CONTROLS**
| **Keyboard** | **Movement** |
| :---: | :--- |
| **W/↑** | **Move up** |
| **A/←** | **Move left** |
| **S/↓** | **Move down** |
| **D/→** | **Move right** |
| **WA/↑←** | **Move Upleft** |
| **WD/↑→** | **Move Upright** |
| **SA/↓←** | **Move Downleft** |
| **SD/↓→** | **Move Downright** |
| **WA/↑← + Space** | **Teleport Upleft** |
| **WD/↑→ + Space** | **Teleport Upright** |
| **SA/↓← + Space** | **Teleport Downleft** |
| **SD/↓→ + Space** | **Teleport Downright** |
| **P** | **Pause Game** |
| **Enter** | **Start Game**|
